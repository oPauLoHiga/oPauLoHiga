## Olá! Eu sou o Paulo Higa 👋

Sou estudante de **Ciência da Computação**, com foco em desenvolvimento de aplicações utilizando **Java e Spring Boot**. Também construo interfaces com **Vue.js** e utilizo **Python** em projetos de análise de dados e aprendizado de máquina.

Gosto de transformar o conteúdo estudado em projetos práticos, documentados e executáveis. Neste perfil você encontrará desde exercícios de fundamentos e orientação a objetos até APIs REST, aplicações web e análises de dados.

- ☕ Desenvolvendo APIs REST com Java, Spring Boot e MySQL;
- 🌐 Criando interfaces responsivas com Vue.js e JavaScript;
- 📊 Explorando dados com Python, pandas e scikit-learn;
- 🎓 Aprendendo continuamente por meio de projetos acadêmicos e pessoais.
